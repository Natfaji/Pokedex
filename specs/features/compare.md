# Compare Pokemon

## Goal

Users can compare any two Pokemon without leaving the app's visual style.

## Acceptance criteria

- A comparison can be opened from a Pokemon detail screen.
- The user can enter one Pokemon name and search for the second Pokemon while typing.
- Both Pokemon are loaded from PokeAPI and show loading and error states.
- Every base stat is shown side by side.
- The Pokemon with the higher value is identified for each stat; ties are shown as equal.
