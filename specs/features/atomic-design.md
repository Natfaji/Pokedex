# Feature: atomic-design

## Purpose

To establish a consistent design system for the Hero Key app, ensuring that components are reusable, maintainable, and scalable.

## Requirements

### FR-ATM-001 - Atomic components

The app MUST use atomic components to build the user interface.

### FR-ATM-002 - Component library

The app MUST have a library of reusable components.

## Acceptance criteria

- The app uses atomic components for its UI.
- If an element is used in multiple places, it is implemented as a reusable component.
- Components MUST be organized according to their level within the atomic design system.
