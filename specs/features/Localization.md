# Feature: Localization

## Purpose

To enable the application to be used in different languages and regions, providing a localized user experience.

## Requirements

### FR-LOC-001 - Language selection

The application MUST provide a way for users to select their preferred language.

### FR-LOC-002 - Translations

All text content in the application MUST be available in the selected language.

## Acceptance criteria

- A user can select their preferred language from a list of supported languages.
- The application displays all text content in the selected language.
- The application maintains the selected language preference across sessions.
- There are no untranslated strings or placeholders anywhere in the application.
